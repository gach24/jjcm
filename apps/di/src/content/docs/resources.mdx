## Comandos habituales

<Tabs>
  <TabItem label="Git" icon="seti:git">

Flujo de trabajo para cada entrega:

```bash
git status                       # ver qué ha cambiado
git add .                        # preparar todos los cambios
git commit -m "Mensaje claro"    # guardar el commit
git push                         # subir a GitHub
```

Crear un repositorio nuevo y subirlo por primera vez:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/NOMBRE-REPO.git
git push -u origin main
```

Otros comandos útiles:

```bash
git log --oneline                # historial resumido
git diff                         # cambios sin preparar
git restore ARCHIVO              # descartar cambios de un archivo
git checkout -b nombre-rama      # crear y cambiar a una rama
git pull                         # traer cambios del remoto
```

  </TabItem>
  <TabItem label="npm y Vite" icon="seti:npm">

```bash
npm install                      # instalar dependencias del proyecto
npm install nombre-paquete       # añadir una dependencia
npm install -D nombre-paquete    # añadir una dependencia de desarrollo
npm run dev                      # servidor de desarrollo (http://localhost:5173)
npm run build                    # build de producción en dist/
npm run preview                  # servir la build localmente
npm run lint                     # comprobar el código con ESLint
npm run format:check             # comprobar el formato con Prettier
```

Crear un proyecto nuevo con Vite:

```bash
npx create-vite@latest nombre-proyecto --template react-ts
```

  </TabItem>
  <TabItem label="Pruebas y docs" icon="seti:config">

```bash
npx vitest run                   # ejecutar las pruebas unitarias una vez
npx vitest                       # ejecutar en modo watch
npx vitest run --coverage        # informe de cobertura
npx playwright test              # pruebas de extremo a extremo
npx playwright test --ui         # interfaz gráfica de Playwright
npx playwright show-report       # abrir el último informe
npm run storybook                # abrir Storybook (http://localhost:6006)
npx typedoc                      # generar la documentación de API
```

  </TabItem>
  <TabItem label="TypeScript" icon="seti:typescript">

```bash
npx tsc --version                # comprobar la versión instalada
npx tsc --init                   # generar un tsconfig.json comentado
npx tsc                          # compilar según tsconfig.json
npx tsc --noEmit                 # solo comprobar tipos
npx tsc --watch                  # recompilar al guardar
```

  </TabItem>
</Tabs>
