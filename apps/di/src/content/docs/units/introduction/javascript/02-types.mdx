En tiempo de ejecución, cada valor en JavaScript tiene un **tipo**. El lenguaje es **dinámico**: no declaras tipos en el código fuente como en Java o C#, pero conviene conocer cómo se clasifican los valores y qué devuelve `typeof`.

<CardGrid stagger>
	<Card title="Primitivos" icon="document">
		Siete tipos **primitivos**: inmutables en el sentido habitual de “no puedes cambiar el valor en sitio”; al reasignar, el identificador apunta a **otro** valor.
	</Card>
	<Card title="Objetos" icon="open-book">
		Todo lo demás es **objeto** (objetos literales, arrays, funciones, fechas, `Map`, `Set`, …): se manipula por **referencia**.
	</Card>
	<Card title="typeof" icon="magnifier">
		Operador unario que devuelve un **string** con el nombre del tipo (con el famoso caso especial de `null`).
	</Card>
</CardGrid>

## Tipos primitivos

Hay **siete**: `string`, `number`, `boolean`, `undefined`, `null`, `symbol` y `bigint`.

### `string`, `number` y `boolean`

```js
let nombre = "Juan";
let saludo = "Hola";
let mensaje = `Bienvenido ${nombre}`;

let edad = 25;
let pi = 3.1416;
let infinito = Infinity;
let noNumero = NaN; // sigue siendo tipo "number"

let activo = true;
let mayor = false;
```

`number` agrupa enteros y coma flotante (IEEE 754). Valores especiales: `NaN`, `Infinity`, `-Infinity`.

### `undefined` y `null`

- **`undefined`**: variable declarada sin asignar, o propiedad inexistente, o función sin `return` explícito.
- **`null`**: ausencia **intencional** de valor (suele asignarse a propósito).

```js
let x;
console.log(x); // undefined

let vacio = null;
```

<Aside type="caution" title="typeof null">
	`typeof null === "object"` es un **error histórico** del lenguaje. Para comprobar `null`, usa `valor === null`.
</Aside>

## `typeof`

```js
typeof "hola";        // "string"
typeof 42;            // "number"
typeof true;          // "boolean"
typeof undefined;     // "undefined"
typeof null;          // "object"  ← peculiaridad
typeof Symbol();      // "symbol"
typeof 10n;           // "bigint"
typeof {};            // "object"
typeof [];            // "object"
typeof function () {}; // "function"
```

Para arrays, `Array.isArray(valor)` es la forma fiable.

## Valores objeto (no primitivos)

Incluyen **objetos**, **arrays**, **funciones** y muchos tipos integrados:

```js
let persona = { nombre: "Ana", edad: 30 };

let numeros = [1, 2, 3, 4];

function saludar() {
	return "Hola";
}

let hoy = new Date();
let mapa = new Map();
let conjunto = new Set([1, 2, 3]);
```

Las **funciones** son objetos invocables; por eso puedes asignarlas, pasarlas como argumentos y devolverlas.

<Aside type="tip" title="Arrays">
	Los arrays son **listas ordenadas por índice** (0, 1, 2, …). Si necesitas conjuntos sin duplicados, mira `Set`.
</Aside>

## Valor vs referencia (idea práctica)

- **Primitivos**: al asignar o pasar a una función, se copia el contenido.
- **Objetos**: varias variables pueden apuntar al **mismo** objeto; mutar propiedades se ve en todas las referencias.

```js {7, 9}
let a = 1;
let b = a;
b = 2;
console.log(a); // 1

const o1 = { x: 1 };
const o2 = o1;
o2.x = 2;
console.log(o1.x); // 2 — mismo objeto
```

## Convención mental

<Steps>

1. Clasifica el valor: ¿primitivo u objeto?
2. Si es objeto, piensa en **referencias** compartidas antes de mutar.
3. Usa `typeof`, `=== null` y `Array.isArray` según lo que necesites comprobar.

</Steps>


## Ejercicios

Resuélvelos en `src/02-types/exercises.js`. Usa `typeof` y `console.log` para comprobar cada respuesta en la consola.

### Básicos

1. Crea una variable de cada tipo: `string`, `number`, `boolean`, `undefined` y `null`. Imprime cada una junto con su `typeof`.

	Salida esperada (una línea por variable):

	```txt
	Ana string
	25 number
	true boolean
	undefined undefined
	null object
	```

2. Convierte la cadena `"42"` a número con `Number()` y el número `42` a cadena con `String()`. Muestra el `typeof` de ambos resultados.
3. Crea un objeto `persona` con las propiedades `nombre`, `edad` y `ciudad`. Accede a `nombre` con notación de punto y a `ciudad` con notación de corchetes. Añade después la propiedad `profesion` y muestra el objeto con `console.table`.
4. Crea un array `numeros` con cinco valores y compara lo que devuelven `typeof numeros` y `Array.isArray(numeros)`.

### Para pensar

5. Predice el resultado de cada línea **antes** de ejecutar. Escribe tus predicciones en un comentario y corrige las que fallen.

	```js
	console.log(typeof null);
	console.log(typeof []);
	console.log(typeof (() => {}));
	console.log(null === undefined);
	console.log(null == undefined);
	```

6. Predice, ejecuta y explica en un comentario por qué `a.x` cambia y `c` no.

	```js
	const a = { x: 1 };
	const b = a;
	b.x = 5;
	console.log(a.x);

	let c = 1;
	let d = c;
	d = 5;
	console.log(c);
	```

7. `Number()` no siempre devuelve lo que esperas. Predice el resultado de cada conversión y comprueba en consola.

	```js
	Number("hola");
	Number("");
	Number(null);
	Number(undefined);
	Number(true);
	Number("3.14");
	```

### Reto

`typeof` tiene huecos: devuelve `"object"` para `null` y para los arrays. Escribe una función `describir(valor)` que devuelva el tipo **real** como cadena: `"null"`, `"array"`, `"function"`, `"object"` o el resultado de `typeof` en el resto de casos. Pruébala con al menos ocho valores distintos.

Salida esperada para algunos casos:

```txt
describir(null)        → "null"
describir([1, 2])      → "array"
describir(() => {})    → "function"
describir({ a: 1 })    → "object"
describir("hola")      → "string"
describir(NaN)         → "number"
```
