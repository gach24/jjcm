En este paso dejaremos lista la **estructura visual mínima** de la app (sidebar + zona principal) para poder integrar después la lógica de informes sin pelearte con el UI.

<Aside type="tip" title="Creación de una rama para el layout">

Antes de tocar el layout, crea una rama específica. Mantiene `main` estable y te facilita revisar/mergear cuando todo compile.

```bash title="Terminal"
git checkout -b feat/layout-base
```

Trabajaremos en `feat/layout-base` hasta completar el layout. Cuando lo verifiques en local, lo integrarás en `main`.

</Aside>

## Configuración del layout base

### Estilos base

Añade estilos base en `src/index.css`. La idea es definir variables CSS (paleta + dimensiones) y una rejilla simple para dividir **Sidebar / Main**.

```css title="src/index.css"
@import "tailwindcss";

@layer base {
  :root {
    --primary: #6366f1;
    --primary-hover: #4f46e5;
    --bg-main: #0f172a;
    --bg-card: #1e293b;
    --text-main: #f8fafc;
    --text-muted: #94a3b8;
    --accent: #38bdf8;
    --sidebar-width: 300px;

    color-scheme: dark;
    color: var(--text-main);
    background-color: var(--bg-main);
  }

  button {
    border-radius: 8px;
    border: 1px solid transparent;
    padding: 0.6em 1.2em;
    font-size: 1em;
    font-weight: 500;
    font-family: inherit;
    background-color: var(--primary);
    color: white;
    cursor: pointer;
    transition: all 0.25s ease;
  }
}

@layer components {
  .app-layout {
    display: grid;
    grid-template-columns: var(--sidebar-width) 1fr;
    height: 100vh;
    background-color: var(--bg-main);
  }
}
```

### Layout base (Sidebar y Main)

Ahora crea el esqueleto del layout en `src/App.tsx`. De momento son dos `<div>` “placeholder” para confirmar que la rejilla funciona.

```diff lang="tsx" title="src/App.tsx"
  function App() {
    return (
+      <div className="app-layout">
+        <div>Sidebar</div>
+
+        <div>Main Content</div>
+      </div>
    );
  }

  export default App;
```

## Componentes

Con el layout base validado, crea los dos componentes principales de UI. Separarlos desde el principio evita que `App.tsx` se convierta en un “God component” cuando empieces con el estado de reportes.

<FileTree>
  - src/ - components/ **nuevo** - sidebar/ - index.tsx - sidebar.tsx - main/ -
  index.tsx - main.tsx - App.tsx - index.css - vite.config.ts - package.json -
  tsconfig.json - ...
</FileTree>

### Sidebar

Crea el componente de la barra lateral en `src/components/sidebar/Sidebar.tsx`. Aquí irá el listado de reportes disponibles (por ahora, contenido de ejemplo).

```tsx {20-26} title="src/components/sidebar/Sidebar.tsx"
import { FileText } from "lucide-react";

export const Sidebar = () => {
  return (
    <aside className="flex flex-col border-r border-white/5">
      <header className="p-6 flex justify-between items-center border-b border-white/5">
        <h1 className="flex items-center gap-3 font-bold text-lg">
          <FileText className="text-primary" />

          <span>Sakila Reports App</span>
        </h1>
      </header>
      <nav className="flex-1 overflow-y-auto p-6">
        <h3 className="text-xs uppercase tracking-wider text-muted mb-4">
          Reportes Disponibles
        </h3>

        <ul>
          {/* TODO: Add reports here */}
          <li className="cursor-pointer p-2 hover:bg-white/10">
            <div className="flex flex-col gap-0.5">
              <span className="truncate font-medium">Reporte 1</span>
              <span className="truncate text-xs text-muted">Descripción</span>
            </div>
          </li>
        </ul>
      </nav>
    </aside>
  );
};
```

### Main

Crea la zona principal en `src/components/main/Main.tsx`. Este componente será el “lienzo” donde renderizarás el reporte seleccionado.

```tsx {12-21} title="src/components/main/Main.tsx"
import { FileText, Play } from "lucide-react";

export const Main = () => {
  return (
    <main className="flex flex-col overflow-hidden">
      <header className="px-10 py-4 bg-slate-800/70 border border-white/10">
        <button className="flex items-center gap-2">
          <Play size={16} /> Re-ejecutar
        </button>
      </header>

      {/* TODO: Add report view here */}
      <section className="flex-1 p-8 overflow-hidden relative flex">
        <div className="flex flex-col items-center gap-4 m-auto text-center">
          <FileText size={64} className="text-muted" strokeWidth={1} />
          <h3>Vista Previa del Reporte</h3>
          <p>
            Selecciona un reporte de la lista de la izquierda para visualizarlo.
          </p>
        </div>
      </section>
    </main>
  );
};
```

## Utilización de los componentes

Sustituye los placeholders de `App.tsx` por los componentes reales (`Sidebar` y `Main`).

```diff lang="tsx" title="src/App.tsx"
+ import { Main, Sidebar } from './components';

  function App() {
    return (
      <div className="app-layout">
-       <div>Sidebar</div>
+       <Sidebar />

-       <div>Main Content</div>
+       <Main />
      </div>
    );
  }

  export default App;
```

```bash title="Terminal"
git add .
git commit -m "Add layout and components"
git push origin feat/layout-base
```
</Aside>
