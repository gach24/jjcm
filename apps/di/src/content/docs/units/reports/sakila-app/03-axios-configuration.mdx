La API REST de **JasperReports Server** vive en otro origen (`http://localhost:8080`) que el de Vite (`http://localhost:5173`). El navegador aplica **CORS**: una petición directa desde React fallaría. En desarrollo resolvemos el problema en **dos pasos**: (1) **proxy** en Vite para que el navegador hable solo con el origen de Vite; (2) **Axios** con `baseURL` y cabeceras hacia `/jasperserver/rest_v2`.

## Paso 1 — Proxy hacia JasperReports Server

Añade en `vite.config.ts` un `server.proxy` que enrute las peticiones que empiecen por `/jasperserver` hacia tu instancia de JRS (por defecto en este módulo, `http://localhost:8080`).

El `configure` que elimina la cabecera `www-authenticate` de la respuesta proxificada evita que el navegador dispare un cuadro de diálogo de autenticación HTTP nativo cuando trabajas con **Basic** desde JavaScript.

```diff lang="ts" title="vite.config.ts"
   export default defineConfig({
     plugins: [tailwindcss(), react()],
+    server: {
+      proxy: {
+        '/jasperserver': {
+          target: 'http://localhost:8080',
+          changeOrigin: true,
+          secure: false,
+          configure: (proxy) => {
+            proxy.on('proxyRes', (proxyRes) => {
+              if (proxyRes.headers['www-authenticate']) {
+                delete proxyRes.headers['www-authenticate'];
+              }
+            });
+          },
+        },
+      },
+    },
   });
```

<Aside type="caution" title="Solo en desarrollo">
  El proxy de Vite **no existe en la build de producción**. En despliegue real
  necesitarás CORS bien configurado en el servidor, un proxy inverso (nginx,
  etc.) o un backend que reenvíe las peticiones.
</Aside>

## Paso 2 — Instancia de Axios

Crea el hook en `src/hooks/useReports.ts`. La instancia usa `baseURL: '/jasperserver/rest_v2'`: en desarrollo Vite la completa contra el proxy; las rutas relativas del cliente coinciden con la API REST v2.

<Aside type="caution" title="Credenciales en el cliente">
	`Basic` con usuario y contraseña en el código es **aceptable solo como demo educativa**. En aplicaciones reales, evita exponer secretos en el frontend: token obtenido de forma segura, backend intermedio, etc.

```env title=".env.local"
VITE_JASPER_REPORTS_SERVER_USER=admin
VITE_JASPER_REPORTS_SERVER_PASSWORD=admin
```

El fichero `.env` se debe añadir al fichero `.gitignore` para que no se incluya en el repositorio.

```gitignore title=".gitignore"
.env
```

</Aside>

```ts title="src/config/jasper-reports-client.ts"
import axios from "axios";

const USER = import.meta.env.JASPER_REPORTS_SERVER_USER;
const PASSWORD = import.meta.env.JASPER_REPORTS_SERVER_PASSWORD;
/**
 * Axios instance to make requests to the Jasper Reports server
 */
const jasperReportsClient = axios.create({
  // En desarrollo, Vite proxy maneja las peticiones a /jasperserver
  // En producción, puedes configurar baseURL si es necesario
  // baseURL: import.meta.env.DEV ? '/jasperserver/rest_v2' : import.meta.env.VITE_BASE_URL,
  baseURL: "/jasperserver/rest_v2",
  headers: {
    /*
     * Codifica las credenciales en Base64 para enviarlas en el header Authorization
     * btoa(`admin:admin`)
     */
    Authorization: `Basic ${btoa(`${USER}:${PASSWORD}`)}`,
  },
});

export default jasperReportsClient;
```

## Paso 3 - Métodos de acceso a la API REST (I)

En primer lugar, vamos a crear un método para comprobar si el servidor de JasperReports está disponible.

```ts title="src/api/jasper-reports-api.ts"
import httpClient from "../config/jasper-report-client";

/**
 * Login to the JasperReports server
 * Only use to check if the server is available
 * @returns True if the login is successful, false otherwise
 */
export const login = async () => {
  try {
    const response = await httpClient.get(`/serverInfo`);
    return response.status === 200;
  } catch (error: any) {
    if (
      error.code === "ERR_NETWORK" ||
      error.message?.includes("ERR_CONNECTION_REFUSED")
    ) {
      console.error(
        "Error de conexión: El servidor JasperReports no está disponible a través del proxy"
      );
    } else {
      console.error("Error en login:", error.message);
    }
    return false;
  }
};
```

Una vez generado el método, vamos a crear otro método para obtener el listado de informes. Podríamos probar si funciona de forma manual sin realizar una batería de pruebas

```diff lang="tsx" title="src/App.tsx"
  import { Main, Sidebar } from './components';

+ import { login } from './api/jasper-report-api';

  function App() {

+   login().then(console.log);

```
