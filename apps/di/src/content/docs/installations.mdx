Para seguir el módulo necesitas tener instaladas las siguientes herramientas en tu equipo. En esta página se detallan los pasos de instalación y las extensiones recomendadas para cada una.

## Instalar Visual Studio Code

<Steps>
  <ol>
    <li><strong>Descarga</strong> el instalador desde <a href="https://code.visualstudio.com/">code.visualstudio.com</a> (elige la versión para tu sistema operativo).</li>
    <li><strong>Ejecuta</strong> el instalador y sigue el asistente. Puedes dejar las opciones por defecto.</li>
    <li><strong>Abre</strong> VS Code y comprueba que se abre correctamente antes de instalar extensiones.</li>
  </ol>
</Steps>

  </TabItem>

## Extensiones para VS Code / Cursor

Las extensiones añaden funciones al editor. Para instalarlas: abre el **panel de extensiones** con el icono de cuadrados en la barra lateral izquierda (o `Ctrl+Shift+X` / `Cmd+Shift+X`), busca el nombre de la extensión y pulsa **Instalar**. También puedes abrir el enlace de cada tarjeta y pulsar **Install** en el marketplace.

<CardGrid stagger>

  <Card title="ESLint" icon="lucide:shield-check">
    **Instalar:** [ESLint en el marketplace](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)

    **Para qué sirve:** Revisa tu código en tiempo real y señala errores, código que no se usa y estilos inconsistentes (comillas, puntos y comas). No ejecuta el código; solo lo analiza.

    **Qué notarás:** Subrayados y iconos en el margen izquierdo del editor. En el panel inferior **Problemas** verás la lista de avisos. Corrigiendo lo que marca aprenderás buenas prácticas casi sin darte cuenta.
  </Card>

  <Card title="Prettier" icon="lucide:sparkles">
    **Instalar:** [Prettier en el marketplace](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)

    **Para qué sirve:** Formatea el código automáticamente (indentación, saltos de línea, espacios). Todo el proyecto se ve uniforme sin que tengas que preocuparte por el estilo.

    **Qué notarás:** Al guardar (`Ctrl+S` / `Cmd+S`) el código se reordena solo. La primera vez puede pedirte que elijas Prettier como formateador por defecto — acepta. Sin guardar: clic derecho → **Format Document**.
  </Card>

  <Card title="Error Lens" icon="lucide:bug">
    **Instalar:** [Error Lens en el marketplace](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)

    **Para qué sirve:** Muestra el mensaje de error o aviso directamente en la línea donde ocurre (inline), en lugar de mirar solo el panel de Problemas.

    **Qué notarás:** Junto a la línea con error verás el mensaje en rojo o amarillo. Localizas el fallo al instante. Si te resulta intrusivo, puedes desactivarla o ajustar su configuración.

    **ID para buscar:** `usernamehw.errorlens`
  </Card>

  <Card title="Live Server" icon="lucide:globe">
    **Instalar:** [Live Server en el marketplace](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

    **Para qué sirve:** Levanta un pequeño servidor web local y abre tus archivos `.html` en el navegador a través de `http://`. Es imprescindible para los ejemplos de JavaScript: abriendo el HTML con doble clic (`file://`) el navegador bloquea los módulos ES y las peticiones `fetch`.

    **Qué notarás:** Aparece un botón **Go Live** en la barra inferior de VS Code y la opción **Open with Live Server** al hacer clic derecho sobre un `.html`. Cada vez que guardes un archivo, la página se recarga sola.

    **ID para buscar:** `ritwickdey.LiveServer`
  </Card>

</CardGrid>

:::tip[Instalación rápida por ID]
En la paleta de comandos (`Ctrl+Shift+P` / `Cmd+Shift+P`) escribe **Extensions: Install Extensions** y luego pega: `ext install dbaeumer.vscode-eslint esbenp.prettier-vscode astro-build.astro-vscode unifiedjs.vscode-mdx usernamehw.errorlens ritwickdey.LiveServer`
:::

## Instalar Git en Windows

Git es el sistema de control de versiones que usarás durante todo el módulo para guardar el historial de tu código y subirlo a GitHub.

<Steps>
  <ol>
    <li><strong>Descarga</strong> el instalador desde <a href="https://git-scm.com/downloads/win">git-scm.com/downloads/win</a> (elige la versión de 64 bits).</li>
    <li><strong>Ejecuta</strong> el instalador y sigue el asistente. Puedes dejar las opciones por defecto, pero asegúrate de que está marcada la opción <strong>Git from the command line and also from 3rd-party software</strong>.</li>
    <li><strong>Elige</strong> Visual Studio Code como editor por defecto cuando el asistente lo pregunte. Así los mensajes de commit se abrirán en el editor que ya conoces.</li>
    <li><strong>Comprueba</strong> que funciona abriendo una terminal nueva y ejecutando `git --version`. Deberías ver el número de versión instalada.</li>
  </ol>
</Steps>

:::note[Git Bash]
El instalador de Windows incluye **Git Bash**, una terminal con comandos de estilo Unix (`ls`, `rm`, `grep`…). Es la terminal recomendada para seguir los ejemplos del módulo en Windows.
:::

  </TabItem>

  <TabItem label="macOS" icon="lucide:apple">

## Instalar Git en macOS

<Steps>
  <ol>
    <li><strong>Abre</strong> la aplicación Terminal y ejecuta `git --version`. Si macOS te ofrece instalar las <em>Command Line Tools</em>, acepta: es la forma más sencilla de tener Git.</li>
    <li><strong>Alternativa con Homebrew</strong>: si ya tienes <a href="https://brew.sh/">Homebrew</a>, ejecuta `brew install git` para obtener una versión más reciente que la del sistema.</li>
    <li><strong>Comprueba</strong> de nuevo con `git --version` que el comando responde correctamente.</li>
  </ol>
</Steps>

  </TabItem>

  <TabItem label="Linux" icon="lucide:terminal">

## Instalar Git en Linux

<Steps>
  <ol>
    <li><strong>Instala</strong> el paquete con el gestor de tu distribución: `sudo apt install git` en Debian o Ubuntu, `sudo dnf install git` en Fedora, `sudo pacman -S git` en Arch.</li>
    <li><strong>Comprueba</strong> que funciona ejecutando `git --version` en la terminal.</li>
  </ol>
</Steps>

  </TabItem>

  <TabItem label="Configuración inicial" icon="lucide:settings">

## Configurar Git por primera vez

Después de instalar Git hay que indicarle **quién eres**. Estos datos se guardan en cada commit que hagas, así que usa el mismo correo que en tu cuenta de GitHub.

<Steps>
  <ol>
    <li><strong>Configura</strong> tu nombre: `git config --global user.name "Tu Nombre"`</li>
    <li><strong>Configura</strong> tu correo: `git config --global user.email "tu@correo.com"`</li>
    <li><strong>Establece</strong> el nombre de la rama principal: `git config --global init.defaultBranch main`</li>
    <li><strong>Revisa</strong> el resultado con `git config --list`. Deberías ver las tres claves que acabas de definir.</li>
  </ol>
</Steps>

:::tip[Cuenta de GitHub]
Necesitarás también una cuenta en [github.com](https://github.com/) para publicar tus prácticas. Regístrate con el mismo correo que has configurado en `user.email` para que tus commits aparezcan asociados a tu perfil.
:::

  </TabItem>

## Instalar Node.js en Windows

Node.js permite ejecutar JavaScript fuera del navegador. Es la base de las herramientas del módulo: React, Vite, Storybook o Electron se instalan y se ejecutan con él.

<Steps>
  <ol>
    <li><strong>Descarga</strong> la versión <strong>LTS</strong> desde <a href="https://nodejs.org/">nodejs.org</a>. LTS significa <em>Long Term Support</em>: es la versión estable y la que debes usar.</li>
    <li><strong>Ejecuta</strong> el instalador y sigue el asistente con las opciones por defecto. Deja marcada la casilla para añadir Node al `PATH`.</li>
    <li><strong>Cierra y vuelve a abrir</strong> la terminal para que reconozca los comandos nuevos.</li>
    <li><strong>Comprueba</strong> la instalación con `node --version` y `npm --version`. Ambos deben devolver un número de versión.</li>
  </ol>
</Steps>

  </TabItem>

  <TabItem label="macOS / Linux" icon="lucide:terminal">

## Instalar Node.js en macOS o Linux

En macOS y Linux lo recomendable es instalar Node con **nvm** (Node Version Manager), que permite tener varias versiones instaladas y cambiar entre ellas por proyecto.

<Steps>
  <ol>
    <li><strong>Instala</strong> nvm siguiendo las instrucciones de <a href="https://github.com/nvm-sh/nvm#installing-and-updating">github.com/nvm-sh/nvm</a>.</li>
    <li><strong>Cierra y vuelve a abrir</strong> la terminal para que se cargue nvm.</li>
    <li><strong>Instala</strong> la última versión LTS con `nvm install --lts` y actívala con `nvm use --lts`.</li>
    <li><strong>Comprueba</strong> la instalación con `node --version` y `npm --version`.</li>
  </ol>
</Steps>

:::note[Alternativa rápida]
Si prefieres no usar nvm, puedes instalar Node desde el paquete oficial de [nodejs.org](https://nodejs.org/) (macOS) o con el gestor de paquetes de tu distribución (Linux). Perderás la posibilidad de cambiar de versión fácilmente.
:::

  </TabItem>

  <TabItem label="Comprobación" icon="lucide:check-check">

## Comprobar que todo está listo

Abre una terminal y ejecuta estos comandos. Si los tres devuelven una versión, tu entorno está preparado.

<Steps>
  <ol>
    <li>`node --version` — debe mostrar una versión <strong>LTS</strong> (par: 20.x, 22.x…).</li>
    <li>`npm --version` — se instala junto a Node, no hay que instalarlo aparte.</li>
    <li>`git --version` — confirma que Git también está disponible.</li>
  </ol>
</Steps>

:::caution[El comando no se reconoce]
Si la terminal responde `command not found` o `no se reconoce como un comando`, casi siempre es porque **no has reiniciado la terminal** después de instalar. Ciérrala, ábrela de nuevo y vuelve a probar.
:::

  </TabItem>
</Tabs>

## Instalar Docker Desktop

Docker Desktop incluye el motor Docker, Docker Compose y una interfaz gráfica. En el módulo lo usarás para ejecutar entornos de desarrollo o servicios en contenedores.

<Steps>
  <ol>
    <li><strong>Descarga</strong> Docker Desktop desde <a href="https://www.docker.com/products/docker-desktop/">docker.com/products/docker-desktop</a> (elige Windows, Mac o Linux según tu equipo).</li>
    <li><strong>Ejecuta</strong> el instalador y acepta los pasos del asistente. En Windows puede pedirte habilitar WSL 2 si aún no está activo.</li>
    <li><strong>Inicia</strong> Docker Desktop desde el menú de aplicaciones. Espera a que el indicador muestre que Docker está en ejecución (icono de ballena en la bandeja del sistema).</li>
    <li><strong>Comprueba</strong> que funciona abriendo una terminal y ejecutando `docker --version`. Deberías ver el número de versión instalada.</li>
  </ol>
</Steps>
