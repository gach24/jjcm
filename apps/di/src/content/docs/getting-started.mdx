**Desarrollo de Interfaces** (código 0488) es un módulo profesional de segundo curso del ciclo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**. Tiene una duración de **80 horas** y su currículo está fijado en el Real Decreto 405/2023 (BOE-A-2023-13221).

El módulo forma parte de la función de desarrollador de aplicaciones multiplataforma y cubre el ciclo completo de una aplicación con interfaz gráfica: diseñarla, construirla con componentes, integrar informes, probarla, documentarla y distribuirla.

## Objetivos

Al terminar el módulo serás capaz de:

- **Construir interfaces de usuario** con componentes reutilizables, estado y eventos.
- **Diseñar interfaces usables y accesibles**, aplicando pautas de estructura, aspecto y mensajes.
- **Integrar informes** generados con herramientas gráficas dentro de una aplicación.
- **Probar la aplicación** con una estrategia de pruebas unitarias, de integración y de extremo a extremo.
- **Documentar** componentes, código y manuales de usuario e instalación.
- **Distribuir** la aplicación como programa de escritorio con su instalador.

## Enfoque del curso

El curso se organiza en torno a la construcción progresiva de aplicaciones reales. Los conceptos se introducen para usarse poco después en el proyecto, no como teoría aislada.

El recorrido tiene seis fases:

1. **Fundamentos aplicados**: JavaScript, TypeScript y Tailwind CSS.
2. **Interfaces con React**: componentes, props, estado, hooks, formularios y rutas.
3. **Aplicación del curso**: desarrollo incremental de GuitarLA.
4. **Informes**: JasperReports Server integrado en una aplicación React.
5. **Escritorio y distribución**: Electron, empaquetado e instalador.
6. **Calidad y cierre**: pruebas, documentación y manuales.

## Resultados de aprendizaje

El BOE define ocho resultados de aprendizaje (RA) para el módulo. Cada unidad del curso indica en su cabecera los RA y criterios de evaluación que trabaja.

| RA | Resultado de aprendizaje |
| --- | --- |
| RA1 | Genera interfaces gráficos de usuario mediante editores visuales utilizando las funcionalidades del editor y adaptando el código generado. |
| RA2 | Genera interfaces naturales de usuario utilizando herramientas visuales. |
| RA3 | Crea componentes visuales valorando y empleando herramientas específicas. |
| RA4 | Diseña interfaces gráficas identificando y aplicando criterios de usabilidad y accesibilidad. |
| RA5 | Crea informes evaluando y utilizando herramientas gráficas. |
| RA6 | Documenta aplicaciones seleccionando y utilizando herramientas específicas. |
| RA7 | Prepara aplicaciones para su distribución evaluando y utilizando herramientas específicas. |
| RA8 | Evalúa el funcionamiento de aplicaciones diseñando y ejecutando pruebas. |

<Aside type="note">
  RA1 y RA2 se trabajan de forma transversal. En este curso las interfaces se construyen con código (React) en lugar de con un editor visual, y las interfaces naturales se tratan de forma introductoria.
</Aside>
