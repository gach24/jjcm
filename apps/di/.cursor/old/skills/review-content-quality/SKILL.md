# Review Content Quality

## Read first

- `AGENTS.md`
- `docs/content-model.md`
- `docs/style-guide.md`
- `docs/workflows/review-content.md`

## Review checklist

- correct folder and slug
- useful `title` and `description`
- clear pedagogical objective
- Spanish phrasing that sounds natural
- enough structure for the content type
- no starter leftovers or generic filler
- links to related parts of the module when useful

## Feedback format

Use this format:

```md
- Correcto:
  - ...
- Mejorar:
  - ...
```

## Verdicts

- `aprobado`
- `aprobado con ajustes menores`
- `necesita reescritura parcial`
