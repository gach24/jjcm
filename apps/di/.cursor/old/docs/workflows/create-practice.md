## Objetivo

Crear una práctica clara, evaluable y conectada con el resto del módulo.

## Ruta recomendada

```text
src/content/docs/practicas/practica-XX.mdx
```

## Pasos

1. Comprueba la numeración ya usada en `practicas/`.
2. Crea la nueva página con slug secuencial.
3. Define objetivo, contexto y requisitos previos.
4. Describe pasos accionables y entregables.
5. Añade criterios de revisión para facilitar corrección y autoevaluación.
6. Enlaza la unidad o vídeo relacionado si existe.

## Plantilla base

```mdx
---
title: Práctica XX · Título breve
description: Trabajo guiado para aplicar una competencia concreta del módulo.
sidebar:
  label: Práctica XX
---

## Objetivo

Qué debe ser capaz de hacer el alumnado al terminar.

## Requisitos previos

- Conocimiento o unidad previa
- Herramienta necesaria

## Desarrollo

1. Paso 1
2. Paso 2
3. Paso 3

## Entregables

- Archivo o proyecto a entregar
- Evidencia adicional si aplica

## Criterios de revisión

- Criterio 1
- Criterio 2

## Ampliación opcional

- Mejora o reto adicional
```

## Criterios de calidad

- debe poder ejecutarse sin asumir contexto oculto;
- los entregables deben ser verificables;
- evita prácticas redactadas como teoría disfrazada.
