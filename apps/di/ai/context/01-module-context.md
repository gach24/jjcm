# Contexto del módulo

Módulo profesional:
0488 - Desarrollo de Interfaces

Ciclo:
Desarrollo de Aplicaciones Multiplataforma (DAM)

Duración:
80 horas

## Finalidad del curso

El curso se organizará en torno a una introducción aplicada a JavaScript y TypeScript, seguida del desarrollo de una o varias aplicaciones en React.

Además, durante el curso:

- se integrarán informes mediante JasperReports Server
- se transformarán aplicaciones en aplicaciones de escritorio para Windows con Electron
- se creará un instalador
- se realizarán pruebas
- se elaborará documentación técnica y de usuario

## Enfoque metodológico

El contenido debe orientarse a la construcción progresiva de aplicaciones reales.
Los conceptos teóricos se introducen para ser utilizados poco después en el proyecto.

## Relación funcional del módulo

El contenido del curso debe alinearse especialmente con:
- desarrollo de interfaces
- creación de componentes
- diseño usable y accesible
- generación de informes
- documentación
- distribución
- pruebas
