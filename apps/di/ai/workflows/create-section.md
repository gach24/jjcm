# Workflow: crear sección

## Objetivo
Generar una sección nueva en MDX lista para Astro Starlight.

## Pasos
1. identificar el tema
2. redactar title y description
3. preparar frontmatter
4. generar introducción breve
5. decidir si conviene CardGrid inicial
6. desarrollar apartados principales
7. insertar ejemplos progresivos
8. añadir Asides útiles
9. añadir resumen rápido
10. añadir convención práctica
11. añadir siguientes pasos
12. revisar YAML, MDX y código
